## 📌 Overview

**AI GYM Coach** is an intelligent fitness assistant that uses **Computer Vision** and **Artificial Intelligence** to monitor exercises in real time. Using your webcam, the system detects body posture, counts repetitions, evaluates exercise form, and provides instant feedback to help users perform workouts safely and effectively.

Whether you're training at home or in the gym, AI GYM Coach acts as your personal trainer.

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/pulibharat/AI-GYM-Coach.git
```

### Move into the project directory

```bash
cd AI-GYM-Coach
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the application

```bash
python main.py
```

## 🎯 How It Works

1. Open your webcam.
2. Detect your body using AI pose estimation.
3. Track body landmarks in real time.
4. Analyze exercise movement.
5. Count repetitions automatically.
6. Provide posture correction feedback.
7. Display workout statistics.
